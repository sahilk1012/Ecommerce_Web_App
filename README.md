# Ecommerce_Web_App
# 🛍️ E-Commerce Website

A responsive and modern **E-Commerce Website** built using HTML, CSS, and JavaScript. This project focuses on creating a clean shopping interface with product listings, product details, cart functionality, and a user-friendly layout.

## 🚀 Features

- 🏠 Home page with attractive hero section
- 🛒 Shopping cart interface
- 📦 Product listing and product details
- 🔍 Product-focused UI and navigation
- 📱 Responsive design for different screen sizes
- 🎨 Clean and modern user interface
- 🧭 Navigation bar with different sections
- 💰 Product pricing and shopping-related information
- ✨ Hover effects and smooth CSS transitions

## 🛠️ Technologies Used

- **HTML5** – Structure and semantic markup
- **CSS3** – Styling, layouts, responsive design, transitions and animations
- **JavaScript** – Interactivity and dynamic functionality
